\section{Problem statement}

The destacking pipeline constrains a magnitude-gap slope $\gamma$ by jointly
fitting $N$ per-cluster weak-lensing profiles.  The log-likelihood is
\begin{equation}
  \ell(\theta) \;=\; \sum_{i=1}^{N} \ell_i(\theta),
  \qquad
  \ell_i(\theta) = -\tfrac{1}{2}\bigl[
    k\ln(2\pi) + \ln|\mathbf{C}_i| +
    \mathbf{r}_i(\theta)^\top \mathbf{C}_i^{-1}\mathbf{r}_i(\theta)
  \bigr],
\end{equation}
where $\mathbf{r}_i(\theta) = \mathbf{d}_i - \mathbf{m}_i(\theta)$ is the
residual between the data vector and the forward model, and $\mathbf{C}_i$
is the per-cluster shape-noise covariance.  The nautilus nested sampler
explores the posterior $p(\theta\mid\{\mathbf{d}_i\}) \propto
\exp[\ell(\theta)]\,\pi(\theta)$ and returns a set of weighted samples.

Calibration tests (running the pipeline on many independent simulated
datasets) show that the run-to-run scatter of the posterior median
$\hat\gamma$ exceeds the mean posterior width by a factor $\approx 2$:
\begin{equation}
  R \;\equiv\; \frac{\sigma_{\rm runs}}{\langle\sigma_{\rm post}\rangle}
  \;\approx\; 2.
\end{equation}
The posteriors are under-dispersed: they capture per-realisation shape-noise
uncertainty but not the additional variance from the finite cluster sample
itself.

\section{Two sources of variance}

The total variance of $\hat\gamma$ can be decomposed as
\begin{equation}
  \mathrm{Var}[\hat\gamma]
  \;\approx\;
  \underbrace{\sigma_{\rm shape}^2}_{\text{shape noise}}
  \;+\;
  \underbrace{\sigma_{\rm samp}^2}_{\text{cluster sample variance}}.
\end{equation}
$\sigma_{\rm shape}^2$ arises because each cluster's profile is measured with
finite background sources; it is proportional to $1/N$ and is the variance
that nautilus correctly captures in its posterior width.
$\sigma_{\rm samp}^2$ arises because the $N$ clusters in the survey are a
random realisation of the cluster population; it depends on the intrinsic
diversity of the cluster sample and is \emph{not} captured by the
shape-noise-only likelihood.

\section{Failed approach: in-sampler bootstrap}

An obvious attempt is to make the likelihood itself stochastic by drawing a
fresh bootstrap resample on every evaluation:
\begin{equation}
  \ell_B(\theta) = \sum_{j=1}^{N} \ell_{I_j}(\theta),
  \qquad I_j \overset{\mathrm{iid}}{\sim} \mathrm{Uniform}\{1,\ldots,N\},
\end{equation}
so that the stochastic noise in $\ell_B$ broadens the posterior.  This fails
in practice because the noise variance of the bootstrap estimator scales as
\begin{equation}
  \mathrm{Var}[\ell_B(\theta)]
  = N\,\mathrm{Var}_i[\ell_i(\theta)]
  \approx N \cdot \frac{k}{2},
\end{equation}
where $k$ is the number of radial bins.  With $N=5000$ and $k=7$
(after the radial cut $R\geq 0.5\,\mathrm{Mpc}$), the standard deviation
of a single bootstrap log-likelihood evaluation is
$\sigma_{\rm noise}\approx\sqrt{5000\times 3.5}\approx 132$.
Since the true log-likelihood \emph{difference} between any two nearby
parameter points is $O(1)$, the accept/reject ratio
$\exp[\ell_B(\theta') - \ell_B(\theta)]$ is dominated by noise.  In
practice the emcee ensemble sampler achieved an acceptance fraction of
$0.0015$ (target $0.2$--$0.5$), meaning each walker accepted only $\sim 8$
proposals per 5500 steps and the chain was effectively frozen.  No number of
MCMC steps resolves this: the fundamental problem is $\sigma_{\rm noise}\gg
\sigma_{\rm signal}$, not a lack of iterations.

\section{Post-hoc bootstrap}

\subsection{Idea}

Instead of resampling on every likelihood call, draw the bootstrap resample
\emph{once} before running the sampler.  The likelihood evaluated inside
nautilus is then fully deterministic; each realisation simply uses a
different fixed subsample of clusters.  Repeating the process for $B$
independent bootstrap draws yields a distribution of posterior medians
$\{\hat\gamma^{(b)}\}_{b=1}^B$ whose spread estimates the total variance
$\sigma_{\rm shape}^2 + \sigma_{\rm samp}^2$.

\subsection{Bootstrap resample}

Given the simulated dataset
$\mathcal{D} = \{(\mathbf{d}_i, \mathbf{C}_i, z_i, \lambda_i, \Delta m_i,
f_{\rm mis,i}, \sigma_{\rm off,i})\}_{i=1}^{N}$,
draw $N$ indices with replacement:
\begin{equation}
  \mathbf{I}^{(b)} = (I_1^{(b)}, \ldots, I_N^{(b)}),
  \qquad
  I_j^{(b)} \overset{\mathrm{iid}}{\sim} \mathrm{Uniform}\{1,\ldots,N\}.
\end{equation}
The expected number of unique indices is
\begin{equation}
  \mathbb{E}\bigl[|\{I_1,\ldots,I_N\}|\bigr]
  = N\left[1 - \left(1-\tfrac{1}{N}\right)^N\right]
  \xrightarrow{N\to\infty} N(1 - e^{-1}) \approx 0.632\,N.
\end{equation}
At $N=5000$ the expected fraction is $63.2\%$; in practice runs show
$\approx 63\%$ unique clusters per draw, confirming the formula.

\subsection{Bootstrap log-likelihood}

The bootstrap log-likelihood for draw $b$ is
\begin{equation}
  \ell^{(b)}(\theta)
  = \sum_{j=1}^{N} \ell_{I_j^{(b)}}(\theta)
  = \sum_{i=1}^{N} m_i^{(b)}\,\ell_i(\theta),
\end{equation}
where $m_i^{(b)} = \#\{j : I_j^{(b)} = i\}$ is the bootstrap multiplicity
of cluster $i$ in draw $b$.  The vector $(m_1^{(b)},\ldots,m_N^{(b)})$ is
drawn from a $\mathrm{Multinomial}(N;\,1/N,\ldots,1/N)$ distribution.  The
expected value is $\mathbb{E}[m_i^{(b)}]=1$ and the variance is
$\mathrm{Var}[m_i^{(b)}] = 1 - 1/N \approx 1$, so on average each cluster
enters once, with Poisson-like fluctuations.

\subsection{Bootstrap posterior}

For each draw $b$, the posterior is
\begin{equation}
  p^{(b)}(\theta)
  \;\propto\;
  \exp\!\left[\ell^{(b)}(\theta)\right]\pi(\theta),
\end{equation}
where $\pi(\theta)$ is the prior (unchanged between draws).  This is a
fully deterministic posterior: nautilus can build its neural-network
surrogate of $\ell^{(b)}$ without interference from noise.

\subsection{Calibration estimator}

After $B$ bootstrap realisations (in practice also drawing fresh lensing
data each time to include shape-noise variance), extract the posterior median
$\hat\gamma^{(b)}$ and the 68\% half-interval $\sigma^{(b)}$ from each run.
The calibration ratio is then
\begin{equation}
  R_{\rm boot}
  = \frac{\sigma_{\rm runs}^{\rm boot}}{\langle\sigma^{(b)}\rangle},
  \qquad
  \sigma_{\rm runs}^{\rm boot}
  = \mathrm{std}\bigl(\hat\gamma^{(1)},\ldots,\hat\gamma^{(B)}\bigr).
\end{equation}
Comparing with the ratio $R$ from the standard run (no bootstrap), one
isolates the contribution of cluster sample variance:
\begin{equation}
  \sigma_{\rm samp}^2
  \;\approx\;
  \left(\sigma_{\rm runs}^{\rm boot}\right)^2
  - \left(\sigma_{\rm runs}^{\rm no\,boot}\right)^2.
\end{equation}
If $R_{\rm boot} > R$, the bootstrap amplified the scatter: sample variance
is non-negligible.  If $R_{\rm boot} \approx R$, sample variance is small
compared to shape noise for this survey design.

\section{Implementation}

\subsection{Algorithm}

\begin{algorithm}[H]
\caption{Post-hoc bootstrap calibration}
\begin{algorithmic}[1]
\For{$b = 1$ to $B$}
  \State Simulate truth catalogue: $N$ clusters with masses, redshifts,
         triaxial shapes, miscentering offsets
  \State Simulate lensing: per-cluster signal $\mathbf{d}_i$ and diagonal
         covariance $\mathbf{C}_i$ ($N\times k$ and $N\times k\times k$)
  \State Assemble: cluster observable table (rows $i = 1\ldots N$),
         $\mathtt{FMISS}_i$, $\mathtt{SIGMA\_OFF}_i$
  \State \textbf{Bootstrap draw:} sample $N$ indices with replacement
         \[I^{(b)} = \mathtt{rng.choice}(N,\; \mathtt{size}=N,\; \mathtt{replace}=\mathtt{True})\]
  \State \textbf{Subsample consistently:} for every per-cluster array $A$,
         form $A^{(b)} = A[I^{(b)}]$
         \begin{itemize}
           \item $\mathbf{d}^{(b)} = \mathbf{d}[I^{(b)},:]$
           \item $\mathbf{C}^{(b)} = \mathbf{C}[I^{(b)},:,:]$
           \item $\mathtt{cluster\_table}^{(b)} = \mathtt{cluster\_table}[I^{(b)}]$
         \end{itemize}
         \textit{Population constants $f_{\rm mis}$ and $\sigma_{\rm off}$ are
         \textbf{not} resampled: every cluster in the model is assumed to share
         the same miscentering fraction and scale, regardless of which clusters
         are drawn.  Pass them as constant arrays of length $n_{\rm resample}$.}
  \State Run nautilus on
         $(\mathbf{d}^{(b)},\mathbf{C}^{(b)},\mathtt{cluster\_table}^{(b)},\ldots)$
         with the standard priors and $\varepsilon = 0$
  \State Extract posterior median $\hat\gamma^{(b)}$ and 68\% CI
         $[\hat\gamma^{(b)}_{\rm lo}, \hat\gamma^{(b)}_{\rm hi}]$
\EndFor
\State Compute $\sigma_{\rm runs}^{\rm boot}$, $\langle\sigma^{(b)}\rangle$,
       and calibration ratio $R_{\rm boot}$
\end{algorithmic}
\end{algorithm}

\subsection{Critical consistency requirement}

All \emph{per-cluster} arrays must be indexed with the same index vector
$I^{(b)}$: the data vectors $\mathbf{d}$, covariance matrices $\mathbf{C}$,
and the cluster observable table (redshifts, richnesses, $\Delta m$, \ldots).
A mismatch among these would silently assign the wrong model to a cluster.

\emph{Population-level} parameters — the miscentering fraction $f_{\rm mis}$
and miscentering scale $\sigma_{\rm off}$ — are \textbf{not} indexed by
$I^{(b)}$.  Because the model cannot identify which individual clusters are
miscentered, it assumes every cluster has the same prior probability
$f_{\rm mis}$ of being offset and the same offset scale $\sigma_{\rm off}$.
These scalars are broadcast to a constant array of length $n_{\rm resample}$
and passed unchanged to every bootstrap run.

\subsection{Radial cut}

The radial cut $R \geq 0.5\,\mathrm{Mpc}$ is applied to the \emph{full}
dataset first (reducing $\mathbf{d}$ and $\mathbf{C}$ from 12 bins to 7),
and the bootstrap index is applied to the already-cut arrays.  This ensures
the cut is based on the fixed radial grid and does not vary between draws.

\section{What the results mean}

Each bootstrap posterior is a valid posterior for the bootstrap-resampled
dataset.  Its width $\sigma^{(b)}$ measures shape-noise uncertainty for
that particular draw.  Because the bootstrap down-weights roughly $37\%$
of clusters to zero and up-weights others, the effective sample size is
slightly smaller than $N$, so $\sigma^{(b)}$ will be slightly larger than
the full-sample $\sigma$ on average.

The run-to-run scatter $\sigma_{\rm runs}^{\rm boot}$, however, receives
contributions from both shape noise \emph{and} bootstrap sample variance.
If the two are independent,
\begin{equation}
  \left(\sigma_{\rm runs}^{\rm boot}\right)^2
  \approx
  \sigma_{\rm shape}^2 + \sigma_{\rm samp}^2.
\end{equation}
Comparing $R_{\rm boot}$ with the baseline $R \approx 2.16$ from the 50-
realisation standard run therefore tells us whether the calibration problem
is dominated by unmodelled sample variance, or whether the under-dispersion
has a different origin (e.g.\ model misspecification in the NFW profile).
